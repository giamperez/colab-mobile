# Colab Mobile

Aplicación móvil desarrollada con **React Native** y **Expo** para la plataforma Colab.

## 🚀 Requisitos previos

- Node.js (versión 18 o superior recomendada)
- npm o yarn
- Expo CLI (
px expo)
- Android Studio / Emulador de Android o Expo Go en un dispositivo físico

## 🛠️ Instalación y ejecución

1. Instalar dependencias:
   `ash
   npm install
   `

2. Iniciar el servidor de desarrollo Expo:
   `ash
   npm run start
   `

3. Ejecutar en Android:
   `ash
   npm run android
   `

4. Ejecutar en iOS (requiere macOS):
   `ash
   npm run ios
   `

5. Ejecutar en Web:
   `ash
   npm run web
   `
